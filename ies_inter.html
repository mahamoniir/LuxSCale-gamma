💡 In Plain English — what this is all about
IES file = a text file that describes exactly how a lamp throws light in every direction. Think of it like a blueprint of the lamp's light beam.
Nadir (0°) = straight down from the lamp — like pointing a flashlight at your feet. 90° = horizontal. Most downlights are strongest at 0°.
Candela (cd) = how strong the light is in one specific direction. It does not change with distance — it's a property of the lamp itself.
Lux (lx) = how much light actually lands on a surface. It does drop with distance — double the distance = ¼ the lux.

In plain English: An IES file is just a plain text file (open it in Notepad — it works!). It has 6 sections: a version stamp, metadata keywords, a tilt flag, one line of numbers describing the lamp, then lists of angles, and finally the brightness values (candela) measured at each angle.

One-line summaries:
🔦 Candela = how strong the lamp shines in one direction. Fixed. Doesn't care about distance.
💡 Lumen = total light output in all directions combined. Also fixed for the lamp.
☀️ Lux = how bright the surface actually is. Shrinks fast — double the distance, ¼ the lux.
